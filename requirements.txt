# Laplace — versões exatas usadas para produzir os resultados do artigo.

# INSTALE O TORCH PRIMEIRO, junto com o torchaudio, a partir do índice da
# PyTorch. As duas versões precisam coincidir: o torchaudio é uma extensão
# compilada contra uma versão específica do torch, e um par desencontrado
# falha com "WinError 127" ao carregar a biblioteca — o que derruba o Demucs.
#
#   pip install torch==2.5.1 torchaudio==2.5.1 \
#       --index-url https://download.pytorch.org/whl/cu121
#
# Em CPU: `pip install torch==2.5.1 torchaudio==2.5.1`. O pipeline roda,
# bem mais devagar nas etapas 2 e 3.
#
# Depois: pip install -r requirements.txt

# Coleta

# O yt-dlp é a única dependência deliberadamente NÃO fixada. Ele não mede
# nada: entrega o mesmo arquivo de áudio que qualquer versão entregaria, e a
# medição começa depois dele. Em compensação, a plataforma muda as defesas
# com frequência, e uma versão fixa para de funcionar em semanas — o que
# tornaria o pipeline irreprodutível justamente por excesso de fixação.
# Testado com 2026.8.19.

# O ctranslate2 é o motor que de fato executa o Whisper; o faster-whisper
# apenas o aciona, e aceita qualquer versão >=4.0,<5. Versões diferentes

# unidade de todo o resto: mover uma fronteira muda o pitch mediano, a
# posição das emoções e os ratios de ato de fala. Sem esta linha, duas
# instalações da mesma data produzem números diferentes.
